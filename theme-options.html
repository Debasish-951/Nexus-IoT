How this maps to the real app

Each palette is a set of CSS variable values (background, sidebar, card, border, primary + a glow accent). When you pick one, I edit the dark-theme block in src/index.css — no component changes, the whole app recolors at once. Say the palette name (or mix: "Ember Grid but with the Cyan Reactor accent").
