Meridian — Structured Enterprise

Design philosophy: Density is a feature, not a flaw. Meridian treats the screen as an instrument panel: crisp 3px geometry, one disciplined accent, strong 1px rules that group information, and tabular numerals everywhere numbers align. It is built for the plant engineer who lives in this application for eight hours a day and needs to see 30 rows without scrolling — while staying clean enough that a screenshot lands well in a board deck. Lineage: SAP Fiori, ServiceNow, Salesforce Lightning.

API Clients — grantable scopes

When this user creates an API endpoint, these are the scopes they may put on it. Write-only is the safe default: it lets them commission a gateway without being able to issue a key that reads the whole platform.

ScopeKindGranted

Read Assets read:assetsread
Read Telemetry read:telemetryread

Read Alarm History read:alarm-historyread
ⓘGranting none means this user cannot create API endpoints at all. Existing credentials are unaffected — this governs what may be created from now on, and it is checked by the API on every create.
