Concept 5 — Slate · Quiet Precision

Monochrome first. No cards, no tinted icon chips, no shadows — structure comes from hairlines, alignment and whitespace. One accent colour (deep teal), spent only on the primary action, the active nav item and the primary data series. Reference points: Vercel dashboard, Stripe docs, Things 3.

What changes: KPIs sit on open ground separated by hairlines instead of in four bordered boxes — the numbers become the loudest thing on the page. Sidebar is text-only with live counts. Every identifier is monospace so a device ID never gets confused with a label.
