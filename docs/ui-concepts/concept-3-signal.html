Signal — Operations Control Room

Design philosophy: Stop pretending this is a generic SaaS product. It is an industrial telemetry platform, so Signal borrows from the tools engineers already trust: a permanent system-status band across the top, monospace for every identifier and numeric value, a colour stripe on the left edge of every row, and alarms rendered above all other content. Highest density of the four — ~22 rows per screen — and the only concept where an operator can tell system health without clicking anything. Lineage: Grafana, Datadog, SCADA/HMI, Bloomberg Terminal.
