Lumen — Executive Light / Editorial

Design philosophy: Built for the person who reviews rather than operates. Lumen borrows from data journalism and management consulting: a serif display face against a clean sans body, numbered sections, and charts presented as captioned figures with a sentence explaining what they show. Warm paper ground and a single deep-navy accent make it print and export to PDF cleanly — the only concept of the four designed to survive being pasted into a board pack. Horizontal navigation frees the full width for content.

Optional. A name helps distinguish several endpoints within one project. If left blank this endpoint will be named EMS Ingest.

Write Telemetry — ingest:write. Verified server-side: a request from this account asking for a read scope is refused with 403 scope_forbidden.
