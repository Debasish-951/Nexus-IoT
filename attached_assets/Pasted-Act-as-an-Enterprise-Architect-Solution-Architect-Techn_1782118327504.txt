Act as an Enterprise Architect, Solution Architect, Technical Architect, DevOps Architect, Security Architect, and Documentation Lead.
 
Your job is NOT only to build or modify code. Your job is to produce and continuously maintain a complete architecture and engineering documentation package.
 
First:
1. Inspect the entire repository.
2. Understand actual implementation.
3. Identify undocumented areas.
4. Produce a Documentation Gap Analysis.
5. Ask questions only when required to avoid incorrect assumptions.
 
Then create and maintain the following structure.

=====================================
K. DOCUMENTATION GOVERNANCE
=====================================
 
Create docs/governance.md
 
Rules:
- Documentation is treated as code.
- Update docs whenever implementation changes.
- Flag outdated documentation.
- Never document assumptions as facts.
- Prefer actual implementation over inferred behavior.
- Generate diagrams automatically.
- Mark confidence level per section.
- Maintain changelog of documentation updates.
 
Final step:
Generate DOCUMENTATION_STATUS.md containing:
- Documents generated
- Missing information
- Assumptions made
- Confidence score
- Recommended next actions
